# Chris · Between Day & Night

互動原型 v0.2：乳白日面呈現 AI 產品／工程；鐵灰夜面呈現視覺實驗。

## 本機執行

在專案根目錄執行 `python3 -m http.server 8000 --directory site`，再開啟 http://localhost:8000 。不需要 npm。

## 內容狀態

案例為研究與構想，照片尚未提供；夜面為 CSS 抽象圖形，不是本人攝影。尚未部署或完成瀏覽器測試。

## 合併方式

將本套件的 site/、docs/、tools/ 及 AGENTS.md 合併入既有專案。本 README 替換舊 README 前先審閱。保留遠端既有 .github/workflows/deploy-pages.yml 及 docs/DEPLOYMENT.md。本套件不包含或改寫它們。

## 部署

符合先前 workflow 的 site/ 發布目錄。公開 Pages 前先檢查完整 Git 歷史與授權。公開儲存庫需要額外核准；此套件沒有改變遠端可見度。
