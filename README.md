# Chris · Between Day & Night

用邏輯打造，用感受觀看。

Chris Yang 的個人品牌網站專案：日間工作室呈現 AI 產品、PM、工程與系統整合；夜間暗房呈現攝影、設計與個人觀察。這不是普通的明暗色系切換，而是同一個人、兩種內容與敘事節奏。

> 狀態：規劃／初始化階段。此儲存庫目前只有說明文件，尚無可執行網站、攝影作品集、測試或部署。

## 產品方向

| 日間工作室 / Build | 夜間暗房 / Observe |
| --- | --- |
| 乳白與石墨色，格線、流程及清楚的註解 | 鐵灰黑與暖灰白，影像、留白及緩慢的觀看節奏 |
| AI PM、工程、SDK／系統整合、產品實驗與實戰筆記 | 攝影系列、設計探索與影像故事 |
| 案例重視問題、角色、取捨、驗證與限制 | 作品重視選片、順序、情境與創作脈絡 |

日／夜切換應由訪客控制，不依時鐘強制切換；兩面共享 Chris 的姓名、導覽及基本資訊架構。互動應可用鍵盤操作、尊重 reduced motion，並在手機上保持順暢。

## 第一版預定範圍

- 雙面首頁與可分享的日／夜入口。
- 日面：定位、產品案例、案例頁、文章入口。
- 夜面：攝影系列、系列頁、影像檢視。
- 共用：關於、手機導覽、可及性、SEO 基礎與錯誤頁。
- 與現有 WordPress 站分開開發；不改動正式站，也不自動匯入或發布既有文章。

技術方向暫定 Astro + TypeScript；尚未建立專案或鎖定版本，實作前需驗證選型與部署需求。

## 內容與真實性

- 未經 Chris 確認，不公開客戶名稱、內部架構、未去識別的工作資料或私人照片。
- 未完成的產品構想標示為構想，不寫成已上線案例；不得虛構職稱、成效或數據。
- 攝影作品需由 Chris 提供並確認授權；展示用素材不得冒稱為其本人作品。
- 文章及外部連結上線前需逐一核對，不以原站首頁連結充作文章永久網址。
