# 日夜切換動畫 v0.3

狀態：待提交與部署驗證。此文件描述預定程式行為，不表示瀏覽器已驗收。

## 設計

採原生 View Transition API，在切換按鈕中心產生圓形擴散，日到夜如日蝕、夜到日如晨光。480ms、無第三方依賴。以新頁面快照的 clip-path 展開，整個可見區域隨內容切換。此版不新增永久運轉的背景動畫。

## 操作與降級

頁首日夜按鈕及頁尾入口共用動畫。鍵盤操作以按鈕中心作起點。頁尾切換時在更新回呼中直接回頂，避免捲動和截圖動畫競爭。初次載入及歷史導航不播放動畫；減少動態或 API 不支援時直接更新。動畫期間忽略重複切換；resize、歷史導航與動態偏好變更可取消轉場。

保留模式記憶、內容狀態標籤與詳情視窗。只改 app.js，既有 CSS、HTML 與部署 workflow 不變。

## 驗收清單（尚待執行）

- 桌面 Chrome／Safari／Firefox 與手機瀏覽器：切換後內容、標題及模式正確。
- Tab／Enter／Space 切換；動畫後焦點仍可見。
- 減少動態開啟或執行中切換偏好：沒有大面積動態。
- 無 View Transition API：內容仍正常切換。
- 快速連點、上一頁／下一頁、視窗縮放：無卡住或遮罩殘留。
- 頁尾入口：回到頂部，光圈涵蓋畫面。
- 原有案例 dialog 可開啟、Esc 關閉並回焦。
