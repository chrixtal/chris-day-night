# 日蝕／晨光轉場 v0.4

狀態：實作待提交；未完成瀏覽器或部署驗收。

## 與 v0.3 差異

v0.3 是 480ms View Transition 快照擴散。此版改用 Web Animations API 與暫時性的 DOM 圓形遮罩：擴散覆蓋畫面，再更新內容並淡出遮罩。不是新內容在光圈中即時揭露，而是有短暫純色覆蓋的換景。無第三方套件。

- 日到夜：560ms 擴散＋190ms 淡出＝750ms，暖銅柔光。
- 夜到日：420ms 擴散＋180ms 淡出＝600ms，暖白柔光。
- 參數集中於 app.js 的 motionProfiles。光圈起點為操作按鈕中心。
- 用小圓放大並以陰影形成光暈；實際陰影與畫面平滑度尚需實機測試。

## 中斷與可及性

減少動態或不支援 Element.animate 時直接換景。視窗縮放、減少動態開啟與 pagehide 時完成模式切換並清理動畫；歷史導航則取消未完成的切換，以 hash 指定世界為準。連點期間忽略額外要求。遮罩不接收指標事件、不進入可及性樹；焦點不由遮罩接管。頁尾切換在畫面被覆蓋後回頂。
