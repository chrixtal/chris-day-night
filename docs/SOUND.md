# 日夜音效 v0.5

狀態：待提交、部署及實機聽感驗收。

## 設計

使用 Web Audio 合成兩個低音量正弦波，無外部音檔或套件。夜面 240→110Hz 與 360→165Hz 下滑，約 710ms 內結束；日面 330→660Hz 與 495→990Hz 上揚，約 570ms 內結束。設定值是數位增益，不代表實際喇叭或耳機音量。

首次預設關閉；頁首加入音效開關並以 chris-sound 記住偏好。載入網站、重新整理、歷史導航與開啟音效開關本身不播放。只在已開啟音效後，使用者觸發有效的日夜切換時播放。減少動態與音效為分開偏好。

## 實作

AudioContext 延至使用者操作才建立／恢復。音效不阻塞動畫或內容；播放失敗靜默處理。關閉開關、歷史導航、動畫中斷、頁面隱藏與 pagehide 停止聲音，播放完成後斷開音訊節點。切換到目前模式或動畫期間重複點擊不額外發聲。音效與動畫同次操作啟動，但裝置音訊延遲仍需實測。

## 待驗收

- 首次進站靜音；開啟後切換日夜有不同聲音。
- 關閉後立即無聲，偏好在重新整理後保留；儲存空間不可用時不報錯。
- 手機 Chrome／Safari、桌面瀏覽器、鍵盤 Enter／Space 可用。
- 聲音未被瀏覽器、系統靜音或裝置輸出設定阻擋。
- 快速連點、切到背景、歷史導航與視窗縮放無殘留聲音；低音量試聽是否有爆音。
- 頁首加入按鈕後手機排版無水平溢出，原有動畫與案例 dialog 正常。

此版本未宣稱通過瀏覽器、可及性或音訊品質驗收。
