# 接手交接

## 已產出

site/index.html、styles.css、app.js：雙面首頁、原創 CSS 主視覺、模式記憶、hash 分享、原生詳情對話框、手機版規則。

## 尚未完成

未推送至 GitHub；未變更可見度；未部署；未跑真實瀏覽器、螢幕閱讀器或效能測試。沒有完整案例獨立路由或攝影系列頁；不是先前 Astro 規劃的完整 MVP。

## 接手順序

1. 檢查 GitHub 當前檔案，避免覆蓋他人更動。
2. 執行 tools/check.py，再開本機 HTTP server。
3. 驗證日夜切換、重新載入、前進後退、模式 hash、localStorage 不可用、手機版及減少動態。
4. 驗證 dialog Esc 關閉與焦點返回。
5. 補真實授權照片、可公開案例及聯絡入口；禁止編造。
6. 修正問題並取得寫入核准後整批推送。
